# 画像一括リサイズ・アップスケール & ファイル自動リネームツール

スマートフォン(Termux環境)だけで動作する、画像処理・ファイル管理の自動化スクリプト集です。
在庫画像サイト向けの大量画像処理パイプラインの一部として、実運用で使用しています。

## できること

### 1. 画像一括アップスケール(upscale.py)
- Pillow(LANCZOS法)を使用した高品質リサイズ
- 出力サイズ: 5632×3072(用途に応じて変更可能)
- フォルダ内の画像を一括処理、処理漏れなし
- 画質劣化を最小限に抑えた補間アルゴリズムを採用

### 2. ファイル自動リネーム(rename.py)
- 日付スタンプ付きの連番リネームを自動化
- 手作業でのファイル管理ミスを防止
- 大量ファイルでも数秒で処理完了

### 3. 全体オーケストレーション(run.py)
- リネーム→アップスケール→フォルダ整理までを1コマンドで実行
- 処理ログを出力し、実行結果を追跡可能

## 動作環境
- Python 3.x
- Pillow
- Termux(Android)/ Linux / macOS で動作確認済み

## 使用例

python upscale.py --input ./before --output ./after --size 5632x3072
python rename.py --folder ./images --prefix stock
python run.py

## 実績
- 本スクリプトを使用し、実際にAI生成画像を用いたストックフォト出品パイプラインを構築・運用中
- 数百枚規模の画像処理を自動化し、手作業を大幅に削減

## カスタマイズ対応可能な範囲
- 出力サイズ・フォーマットの変更
- リネームルールの変更(日付形式、プレフィックス、連番桁数など)
- 他のクラウドストレージ(Google Drive等)との連携
- Webスクレイピングとの組み合わせによる完全自動化
